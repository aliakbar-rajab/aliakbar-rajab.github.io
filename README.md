# وب‌سایت بنیان فولاد داریا

وب‌سایت فارسی و راست‌به‌چپ «بنیان فولاد داریا / Bonyan Foulad Daria». پروژه یک
سایت استاتیک React است که با Vite ساخته و از طریق GitHub Pages منتشر می‌شود.

## اجرای محلی

نیازمندی: Node.js 22.13 یا جدیدتر.

```bash
npm ci
npm run dev
```

## کنترل کیفیت

فرمان زیر lint، بررسی TypeScript، تست‌های منطق و قرارداد محتوا، build تولید و
تست خروجی نهایی را اجرا می‌کند:

```bash
npm run verify
```

GitHub Actions همین فرمان را پیش از انتشار اجرا می‌کند و فقط پوشه `dist` را به
GitHub Pages می‌فرستد.

## قیمت‌های روز

قیمت میلگرد، تیرآهن، ورق، پروفیل، لوله، نبشی، ناودانی و محصولات مفتولی در
اجرای زمان‌بندی‌شده از منبع بازار دریافت و پیش از ذخیره، از نظر ساختار و
سازگاری معنایی اعتبارسنجی می‌شود. اجرای دستی بروزرسانی:

```bash
npm run prices:update
```

دریافت ناقص یا نامعتبر با کد خطا متوقف می‌شود و منتشر نخواهد شد. GitHub Actions
هر چهار ساعت نسخه معتبر تازه را مستقیم روی شاخه اصلی (`main`) ثبت می‌کند؛
بنابراین هر build همیشه آخرین داده معتبر ثبت‌شده را مصرف می‌کند. برای
اعتبارسنجی داده موجود بدون دسترسی شبکه:

```bash
npm run prices:validate
```

## ارتباط فروش

این وب‌سایت عمداً فرم فروش یا ذخیره اطلاعات شخصی ندارد. تمام اقدام‌های استعلام
به شماره‌های تلفن تأییدشده متصل هستند.

## پیش‌بارگذار

پیش‌بارگذار سبک حداکثر یک‌بار در هر نشست مرورگر و حداکثر برای ۱٫۲ ثانیه نمایش
داده می‌شود، دکمه عبور دارد، کاهش حرکت سیستم‌عامل را رعایت می‌کند و در هر خطای
اسکریپت، صفحه اصلی به‌صورت پیش‌فرض قابل مشاهده می‌ماند.
