# وب‌سایت بنیان فولاد داریا

وب‌سایت فارسی و راست‌به‌چپ «بنیان فولاد داریا / Bonyan Foulad Daria». پروژه یک
سایت استاتیک React است که با Vite ساخته و از طریق GitHub Pages منتشر می‌شود.

## اجرای محلی

نیازمندی: Node.js 22.13 یا جدیدتر.

```bash
npm ci
npm run dev
```

## کنترل کیفیت

فرمان زیر lint، بررسی TypeScript، تست‌های منطق و قرارداد محتوا، build تولید و
تست خروجی نهایی را اجرا می‌کند:

```bash
npm run verify
```

GitHub Actions همین فرمان را پیش از انتشار اجرا می‌کند و فقط پوشه `dist` را به
GitHub Pages می‌فرستد.

## ارتباط فروش

این وب‌سایت عمداً فرم فروش یا ذخیره اطلاعات شخصی ندارد. تمام اقدام‌های استعلام
به شماره‌های تلفن تأییدشده متصل هستند.

## پیش‌بارگذار

ویدیوی پیش‌بارگذار حداکثر یک‌بار در هر نشست مرورگر نمایش داده می‌شود، دکمه عبور
دارد، کاهش حرکت سیستم‌عامل را رعایت می‌کند و در هر خطای اسکریپت یا رسانه، صفحه
اصلی به‌صورت پیش‌فرض قابل مشاهده می‌ماند.
